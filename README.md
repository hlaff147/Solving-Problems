# 🧠 Solving Problems & Tech Studies

Repository dedicated to coding challenge solutions from various platforms (LeetCode, CodeWars, HackerRank) and theoretical study notes on software engineering and system design.

---

## 📂 Repository Structure

The project is structured into two main directories:

*   **[`code/`](./code/)**: Source code files for coding challenges, organized by platform.
    *   **[`leetcode/`](./code/leetcode/)**: Solutions to LeetCode problems (Python, SQL).
    *   **[`codewars/`](./code/codewars/)**: Solutions to CodeWars challenges (Python).
    *   **[`hackerrank/`](./code/hackerrank/)**: Solutions to HackerRank challenges (Python).
*   **[`theory/`](./theory/)**: Technical summaries, notes, and theoretical study material.
